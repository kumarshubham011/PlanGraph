# Procedure: Cycle Count and Stock Adjustments

Type: standard operating procedure. Owner: Warehouse.

A cycle count is a physical count of a part to check the system quantity.

- High-volume purchased parts are counted every month.
- If the count differs from the system by more than 10%, the system quantity is corrected and Supply Planning is told the same day.
- A large negative adjustment can create an immediate shortage. Supply Planning must check weeks of cover and open purchase orders for the part.
