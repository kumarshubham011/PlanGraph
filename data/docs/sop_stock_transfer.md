# Procedure: Stock Transfer Between Locations

Type: standard operating procedure. Owner: Warehouse.

Stock can be moved between storage locations and work centres to cover a shortage.

- Check on-hand stock by location before raising a transfer.
- Transfers inside the plant (for example from Miscellaneous Storage to Subassembly) take one working day.
- A transfer needs no cost approval, so it is the first option to check before expediting.
- Never transfer stock that is already reserved for a work order in progress.
